# نقشه مسیرها

همه مسیرها با میدلور سراسری `app/middleware/auth.global.ts` محافظت می‌شوند
(بذرپاشی دمو + گاردها). ستون «دسترسی» یعنی چه کسی صفحه را می‌بیند؛ ریدایرکت‌ها در پرانتز.

| مسیر | هدف | دسترسی | اقدامات اصلی | موجودیت‌های مرتبط |
| --- | --- | --- | --- | --- |
| `/` | داشبورد «الان در ساختمان چه خبر است؟» | عمومی (نمای وابسته به نقش) | ناوبری سریع، کارت شارژ/مالی | Building, Announcement, ProblemReport, Charge |
| `/auth/login` | ورود (رمز عبور؛ OTP غیرفعال) | فقط کاربر خارج‌شده (ورودِ کاربر لاگ‌شده → `/`) | ورود، پرکردن حساب دمو | AuthUser |
| `/auth/register` | ثبت‌نام مدیر/ساکن | فقط کاربر خارج‌شده | ثبت‌نام | AuthUser |
| `/onboarding` | ویزارد ۳ مرحله‌ای ساخت ساختمان | مدیر بدون ساختمان | ساخت ساختمان، افزودن/ویرایش واحد، ساخت دعوت | Building, Unit, Invitation |
| `/join` | پیوستن با کد دعوت (+پیش‌پر از `?code=`) | ورود لازم برای پیوستن؛ کاربر خارج‌شده → ذخیره کد و `/auth/login` | بررسی کد، پیش‌نمایش، پیوستن | Invitation, Building, Member |
| `/building` | نمای کلی ساختمان | ورود + عضویت (بدون ساختمان → هدایت) | ویرایش اطلاعات (مدیر)، تماس با مدیر | Building, Unit, Member |
| `/building/units` | مدیریت واحدها | ورود + عضویت | افزودن/ویرایش/حذف واحد، تخصیص ساکن (مدیر) | Unit, Member |
| `/building/members` | اعضای ساختمان | ورود + عضویت | افزودن/حذف عضو، تخصیص واحد (مدیر) | Member, Unit |
| `/building/invite` | دعوت‌نامه‌ها | ورود + عضویت؛ فقط مدیر (ساکن → `/building`) | ساخت/حذف کد، کپی/اشتراک | Invitation |
| `/announcements` | فهرست اطلاعیه‌ها | ورود + عضویت | مشاهده؛ ایجاد (مدیر) | Announcement |
| `/announcements/new` | ایجاد اطلاعیه | فقط مدیر (ساکن → `/announcements`) | ثبت با اهمیت/تصویر | Announcement |
| `/announcements/[id]` | جزئیات اطلاعیه | ورود + عضویت | ویرایش/حذف (مدیر) | Announcement |
| `/announcements/[id]/edit` | ویرایش اطلاعیه | فقط مدیر | به‌روزرسانی | Announcement |
| `/problems` | گزارش مشکلات با فیلتر وضعیت/دسته | ورود + عضویت | مشاهده (مدیر همه، ساکن گزارش‌های خود)، ایجاد | ProblemReport |
| `/problems/new` | ثبت مشکل | ورود + عضویت | ایجاد با دسته/تصویر | ProblemReport |
| `/problems/[id]` | جزئیات مشکل | ورود + عضویت؛ ساکن فقط گزارش خود (وگرنه حالت «دسترسی مجاز نیست») | تغییر وضعیت (مدیر) | ProblemReport |
| `/charges` | فهرست شارژها | ورود + عضویت | مشاهده وضعیت خود (ساکن) / پیشرفت پرداخت (مدیر) | Charge, Payment |
| `/charges/new` | ایجاد شارژ | فقط مدیر (ساکن → `/charges`) | ثبت عنوان/مبلغ/دوره/سررسید | Charge |
| `/charges/[id]` | جزئیات شارژ | ورود + عضویت | ثبت/حذف پرداخت، حذف شارژ (مدیر) | Charge, Payment, Member |
| `/expenses` | فهرست هزینه‌ها (شفاف) | ورود + عضویت | مشاهده همه؛ حذف (مدیر) | Expense |
| `/expenses/new` | ثبت هزینه | فقط مدیر (ساکن → `/expenses`) | ثبت با دسته/تاریخ/رسید | Expense |
| `/finances` | شفافیت مالی | ورود + عضویت | نمای درآمد/هزینه/مانده/سهم‌ها | Charge, Payment, Expense |
| `/services` | دایره خدمات: جستجو + فیلتر دسته | ورود + عضویت | جستجو، فیلتر، تماس | ServiceProvider, ServiceCategory |
| `/services/[id]` | جزئیات ارائه‌دهنده | ورود + عضویت | تماس (`tel:`)، سوئیچ «مورد اعتماد» (مدیر) | ServiceProvider |
| `/notifications` | مرکز اعلان‌ها | ورود | خواندن/بازکردن، خواندن همه | AppNotification |
| `/account` | پروفایل | عمومی (خارج‌شده حالت ورود می‌بیند) | ویرایش نام، منوی ساختمان/تنظیمات | AuthUser, Building, Member |
| `/settings` | تنظیمات | عمومی (خارج‌شده حالت ورود می‌بیند) | تم روشن/سیستم/تاریک، درباره، خروج | — |
| `/admin` | مدیریت کل پلتفرم | فقط سوپرادمین (ناشناس → ورود، غیرسوپرادمین → `/`) | مشاهده ساختمان‌ها/کاربران/ارائه‌دهندگان/آمار | Building, AuthUser, ServiceProvider |

## ناوبری

- ناوبری پایین (موبایل) و هدر (دسکتاپ) از یک منبع: `useAppNavigation()` →
  خانه `/`، ساختمان `/building`، خدمات `/services`، حساب من `/account`.
- زنگوله هدر → `/notifications` با بج تعداد خوانده‌نشده.
- مسیرهای پویا (`[id]`) برای شناسه نامعتبر حالت «پیدا نشد» دارند، نه خطای خالی.

## مسیرهای حذف‌شده/مرده

- صفحه ماک قدیمی «درخواست خدمات» (`/services` فاز ۱) با دایره خدمات جایگزین و حذف شد.
- هیچ مسیر یتیم یا تکراری وجود ندارد؛ همه `to`/`router.push`/`navigateTo` به صفحات موجود اشاره می‌کنند.
